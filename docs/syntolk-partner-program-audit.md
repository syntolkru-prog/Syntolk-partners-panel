## Что дополнительно проверено в интерфейсе

- Админка: список партнёров открывает единую карточку с KPI, ссылками, начислениями, выплатами, условиями, уровнем и CloudPayments-статусом.
- Админка: `/payouts` показывает общий реестр по всем партнёрам; ручную выплату в статусе `pending` можно подтвердить из таблицы.
- Кабинет партнёра: при отсутствии принятой версии условий показывается обязательное подтверждение; после принятия версия попадает в историю.
- Бренд локального tenant-настроен на `Syntolk`; в проверенных экранах меню и ключевые подписи отображаются на русском.

## Что нужно для запуска на syntolk.ru

1. Адрес и API-ключ Syntolk backend, который передаёт `userId`, `registration`, `payment`, `recurring_payment`, `refund`, `subscription_changed` и `subscription_cancelled`.
2. Merchant ID и секрет CloudPayments, URL webhook для pay/recurrent/refund и подтверждённый способ payout/сплита партнёрских выплат.
3. Решение: выплаты пока вручную через CloudPayments или включаем их payout API после выдачи доступа к продукту.
4. SMTP/Postmark для писем партнёрам и, если нужен Telegram, bot token и chat-id/механика подписки.
5. Публичный роутер на `syntolk.ru` с проксированием `/?ref=...` и UTM в router-сервис.
6. Финальная версия правил партнёрской программы и политика: 20% recurring, holdback, возвраты, минимальная сумма выплаты и уровни партнёров.
