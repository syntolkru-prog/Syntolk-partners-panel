# Syntolk Partners Panel

Рабочая основа партнёрской программы Syntolk.

## Что уже заложено

- отдельный партнёрский кабинет;
- полноценная административная панель;
- recurring-комиссии: одна привлечённая учётная запись может создавать много платежей и много комиссий;
- поддержка возвратов и корректировок;
- ручные выплаты через сущности `Payout` / `PayoutItem`;
- защита от повторной обработки платежей через уникальный `externalTransactionId` и `WebhookEvent.eventKey`;
- модель партнёров со статусами, индивидуальной ставкой комиссии и cookie window.

## Стек

- Next.js 16
- React 19
- TypeScript
- Prisma
- PostgreSQL

## Локальный запуск

```bash
cp .env.example .env
npm install
npx prisma generate
npm run dev
```

Открыть:

- `/partner` — партнёрский кабинет;
- `/admin` — административная панель.

## Финансовая модель

```text
Partner
  -> Referral (привлечённый пользователь)
      -> Payment #1 -> Commission #1
      -> Payment #2 -> Commission #2
      -> Refund     -> корректировка
  -> Payout (ручная выплата)
```

Базовая ставка — 20%, но хранится на уровне партнёра и может быть индивидуальной.
